P9 [Normal]: 본 문서는 제조·물류 공장 운영 지원 AI 에이전트(가칭 Factory Operation AI Agent, 이하 '에이전트')의 사용자 요구사항을 정의한다. 본 문서에 정의된 요구사항은 이후 기능 명세(FS), 설계, 검증(테스트) 활동의 기준이 된다.

P13 [List Paragraph]: 시스템 경계: 채팅 UI 및 웹 애플리케이션 서버, Multi-SLM 엔진(Clas·Plan·Proc), RAG Vector DB 및 RDB까지를 본 프로젝트의 구축 범위로 한다.

P34 [Heading 2]: 2.1 배경 및 현황
P35 [Heading 3]: 2.1.1. 파편화된 시스템과 수작업 탐색 ▶ 설비 비가동 시간(Downtime) 증가
P36 [List Paragraph]: MES·ERP 등 개별 시스템에 일일이 접속해야 하며, 장애 발생 시 종이/PDF 매뉴얼과 과거 일지를 직접 검색하느라 초동 조치 및 정비가 지연됨
P37 [List Paragraph]: 개선 필요성: (자연어 인터페이스 기반 즉시 조회) 복잡한 시스템 조작 없이 질의응답만으로 매뉴얼 및 공정 데이터를 즉시 조회하여 비가동 시간을 최소화해야 함
P38 [Heading 3]: 2.1.2. 숙련공 경험(암묵지) 의존 ▶ 인력 및 품질 격차 심화
P39 [List Paragraph]: 공정 노하우가 체계화되지 않고 개인 경험에 의존하여, 숙련공 부재 시 대응력이 떨어지고 신규 인력의 OJT 지연 및 작업자별 품질 편차가 발생함
P40 [List Paragraph]: 개선 필요성: (현장 지식 통합 및 표준화) 숙련공 노하우와 이력을 데이터화하여 초보자도 숙련공 수준의 표준 대응이 가능하도록 지원 필요
P41 [Heading 3]: 2.1.3. 비정형 데이터 방치 및 IT 의존 ▶ 의사결정 지연
P42 [List Paragraph]: 정비 일지 등 현장 텍스트 데이터가 활용되지 못하고 사장되며, 공정 데이터 분석 시 매번 관련 담당자에게 쿼리를 요청해야 해 즉시 대응이 어려움
P43 [List Paragraph]: 개선 필요성: (현장 중심의 실시간 자율 분석) IT 담당자 경유 없이 현장에서 직접 자연어로 데이터 분석하고 시각화 지원
P44 [Heading 3]: 2.1.4. 수동 보고서 작성 ▶ 현장 행정 부담 가중
P45 [List Paragraph]: 정비 이력 및 원인 분석을 직접 타이핑하여 작성하므로, 정작 중요한 예방 보전 및 공정 개선 업무 집중도가 떨어짐
P46 [List Paragraph]: 개선 필요성: (행정 업무 자동화) 음성·텍스트 입력으로 보고서를 자동 생성하여 현장 엔지니어의 본업(품질·보전) 집중도를 제고해야 함
P47 [Heading 2]: 2.2 목표
P48 [Normal]: 제조 현장 물류 자동화 설비(AGV, RGV, 컨베이어, AS/RS, Gantry, S/C 등)의 알람 대응, 보전 SOP, 자재 및 공정 재고(WIP) 재고 탐색 시간을 단축하고, 안전한 물류 설비 제어 요청 체계를 제공하여 공장 물류 운영 효율성을 극대화한다.
P49 [List Paragraph]: 설비 알람 대응 시간 단축: 알람 발생 시 설비별 원인·조치 이력과 보전 SOP를 자연어 질의로 즉시 제공하여 초동 조치 지연을 해소하고 설비 비가동 시간을 감축한다.
P50 [List Paragraph]: 보전 지식 표준화: 숙련공의 정비 노하우와 조치 이력을 데이터화하여 경력에 관계없이 동일한 수준의 표준 대응이 가능하도록 지원한다.
P51 [List Paragraph]: 재고·공정 데이터 자율 분석: 자재 및 공정 재고(WIP)의 위치·수량을 IT 담당자 경유 없이 현장에서 직접 자연어로 조회·분석하고 시각화하여 탐색 시간을 단축한다.
P52 [List Paragraph]: 현장 행정 업무 자동화: 음성·텍스트 입력 기반으로 정비 일지 및 보고서를 자동 생성하여 엔지니어가 예방 보전과 공정 개선에 집중할 수 있도록 한다.
P53 [List Paragraph]: 안전한 설비 제어 요청 체계: 물류 설비에 대한 제어 요청을 권한·승인·감사 이력이 관리되는 절차로 수행하여 오조작 및 안전 사고 위험을 통제한다.
P54 [Heading 2]: 2.3 시스템 구성 개요
P55 [Normal]: 2.3.1. 시스템 구성도
P56 [Normal]: 
P57 [Normal]: 본 시스템은 Application, Agent Engine, Data, Relay, Factory Site의 5개 계층으로 구성된다. 사용자는 웹 브라우저 또는 현장 태블릿의 채팅 화면에서 자연어로 질의하며, 질의와 응답 이력은 Application 계층을 거쳐 Data 계층에 저장된다. Agent Engine 계층은 질의의 의도를 분류하고 처리 절차를 수립한 뒤 실행하며, 보전 SOP 및 정비 매뉴얼 등 지식 탐색은 Data 계층의 지식 저장소를 직접 참조한다. 반면 재고·설비 상태 등 외부 데이터 조회와 알람 원격 리셋 등 제어 요청은 예외 없이 단일 접점인 Relay 계층의 중계 서버를 경유하여 Factory Site 계층의 MES·WMS 및 설비 PLC로 전달된다.
P58 [Normal]: 2.3.2. 주요 구성 요소
P59 [Normal]: 
P60 [Normal]: 2.3.3. 외부 연계 시스템
P61 [List Paragraph]: 에이전트는 MES, WMS, 설비 PLC 등 외부 시스템과 직접 통신하지 않는다.
P62 [List Paragraph]: 모든 외부 데이터 조회(재고, 체류 시간 등) 및 제어 요청(알람 원격 리셋, Notification 발송)은 약속된 단일 접점인 중계 서버 REST API 인터페이스를 경유한다.
P63 [List Paragraph]: 에이전트가 직접 참조하는 데이터는 권한이 부여된 내부 지식 저장소(보전 SOP 및 정비 매뉴얼)로 한정한다.

R1: URS | User Requirements Specification — 사용자 요구사항 명세서
R2: FS / DS | Functional Specification(기능 명세서) / Design Specification(설계 문서)
R3: 프롬프트 (Prompt) | 사용자가 에이전트에 입력하는 텍스트·음성·파일 형태의 작업 지시문
R4: SLM | Small Language Model — 제조·물류 및 설비 보전 도메인에 최적화하여 온프레미스 환경에서 구동되는 경량 언어 모델
R5: Multi-SLM | 의도 분류(Clas-SLM), 파이프라인 계획(Plan-SLM), 실행·가공(Proc-SLM)으로 모듈화된 역할 분담형 에이전트 엔진 구조
R6: RAG | Retrieval-Augmented Generation — 외부 지식 DB(SOP, 매뉴얼 PDF)에서 관련 문단을 검색하여 환각 없이 응답하는 기술
R7: 중계 서버 (Relay Server) | 현장 설비(PLC·DB) 직접 접근을 차단하고 안전 검증 및 규격화된 REST API 통신을 전담하는 단일 관문
R8: Function Calling | 자연어 프롬프트에서 파라미터를 추출하여 중계 서버 REST API 규격(JSON Schema)에 맞게 호출하는 SLM 기능
R9: TAG (Text-to-SQL) | 자연어를 DB 쿼리로 자동 변환하는 기술. 본 프로젝트에서는 DB 과부하 및 오작동 방지를 위해 사용하지 않음
R10: Audit Log | 설비 원격 제어 실행 시 일시·요청자·승인자·중계 서버 응답을 변경 불가하게 기록하는 감사 이력 데이터
R11: RBAC | Role Based Access Control — 역할(Viewer·Operator·Admin) 기반 접근 제어
R12: AGV | Automated Guided Vehicle — 궤도를 따라 자재 및 공정 재고을 자동 이송하는 무인 이송차
R13: RGV | Rail Guided Vehicle — 레일을 따라 공정 간 공정 재고(WIP)을 고속 수평 이송하는 무인 궤도차
R14: S/C | Stacker Crane — 자동 창고 랙 사이에서 자재를 수평·수직으로 적재 및 반출하는 고단 적재 크레인
R15: AS/RS | Automated Storage & Retrieval System — 자재·공정 재고(WIP)을 무인 고밀도 적재 및 입출고 관리하는 자동 창고 설비
R16: Loader / Unloader | 자재·공정 재고(WIP)을 설비나 컨베이어에 자동 투입·하역하는 물류 자동화 장치
R17: 공정 재고(WIP) (공정 재고) | 단위 공정을 마치고 후속 가공/조립 공정 투입 전 단계에 있는 중간 생산품 및 공정 재고(WIP)
R18: WIP | Work In Process — 공정과 공정 사이 버퍼 구역에 대기·적재 중인 공정 재고(WIP) 재고
R19: 체류 시간 (Dwell Time) | 공정 지연 방지 및 품질 관리 및 선입선출 관리를 위해 WIP 버퍼 구역에서 관리되는 대기 시간
R20: FIFO | First In First Out — 먼저 입고된 자재를 먼저 출고하는 선입선출 관리 원칙
R21: SOP | Standard Operating Procedure — 설비 장애 발생 시 준수해야 하는 표준 점검 및 조치 가이드 문서
R22: MES / WMS | Manufacturing Execution System(제조 실행 시스템) / Warehouse Management System(창고 관리 시스템)
R23: PLC | Programmable Logic Controller — 물류 설비의 물리적 동작을 하드웨어 레벨에서 직접 제어하는 산업용 제어 장치
R24: Topology View | 공장-라인-설비-유닛 간 계층 구조와 알람 집중 구역을 시각화한 화면
R25: MTTR | Mean Time To Repair — 고장 발생부터 복구 완료까지의 평균 소요 시간
